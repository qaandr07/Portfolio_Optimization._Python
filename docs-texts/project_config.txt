project_config.py
В этом файле лежат основные настройки проекта.

Основные переменные:
- ASSETS — словарь доступных активов.
- ACTIVE_ASSETS — список активов, которые используются в запуске проекта.
- START_DATE — дата начала загрузки исторических данных.
- END_DATE — дата окончания загрузки исторических данных.
- NUM_PORTFOLIOS — количество случайных портфелей для Monte Carlo.
- TRADING_DAYS_PER_YEAR — количество торговых дней в году.

Файл нужен, чтобы хранить настройки проекта в одном месте
