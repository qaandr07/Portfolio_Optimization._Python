Реализована первая итерация проекта. Все сделано в одном коммите и одним мердж реквестом, так как фичи связаны друг с другом, и невозможно пользоваться одними без других.

Что сделано:

1. Загрузка данных
Добавлена загрузка исторических данных по выбранным активам через yfinance.
Из загруженных данных берутся цены открытия, после чего они преобразуются в дневные доходности.

2. Таблица корреляций
Добавлен расчёт корреляций между активами.
Также строится heatmap, чтобы было удобнее визуально сравнивать взаимосвязи между активами.

3. Monte Carlo портфели
Добавлена генерация случайных портфелей.
Все портфели строятся без short selling: веса активов неотрицательные, а их сумма равна 1.
Для каждого портфеля считается годовая доходность и годовой риск.
Результат отображается на графике риск–доходность.

4. Efficient Frontier
Добавлено построение эффективной границы.
Граница строится без short selling, чтобы она соответствовала портфелям, которые генерируются методом Monte Carlo.
Для расчёта используется оптимизация через scipy с ограничениями на веса активов.

Также были добавлены:
- визуализация цен активов;
- файл с настройками проекта;
- вспомогательные функции;
