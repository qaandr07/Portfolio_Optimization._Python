This module implements the part 8 investor utility feature.

Main function:
- analyze_indifference_curve

Inputs:
- simulation dictionary
- frontier dictionary
- risk_aversion parameter

Outputs:
- optimal investor weights on the efficient frontier
- return, risk and utility of the chosen portfolio
- optional indifference curve plot

Dependencies:
- efficient_frontier.py
- common_utils.py

Example:
- utility = analyze_indifference_curve(simulation, frontier, risk_aversion=3.0)
